### 🚀 Currently Building

> Public, clean-room reimplementations of production patterns — no proprietary code or data. Each solves a real problem.

- 🤖 **security-findings-mcp-server** — exposes read-only SAST/SCA/DAST findings to LLM agents so teams can triage and ask questions in natural language instead of digging through scanner UIs.
- 🔎 **mcp-security-scanner** — audits MCP servers for tool poisoning, prompt-injection surface, and over-broad tool permissions. *(Agentic-AI security is the newest, least-crowded 2026 niche.)*
- ☸️ **k8s-incident-rca-agent** — an LLM agent that correlates pod events, logs, and cluster state to pinpoint *what broke and why* in production (OOMKilled, crashloops, misconfig) — going past plain-English explanations to root-cause + suggested fix, the hardest part of running K8s.
- 🔐 **k8s-runtime-security-triage** — pairs Falco/Trivy runtime and CVE signals with an LLM to rank real threats over noise, so on-call sees exploitable risk in context instead of a wall of alerts.
- 🛡️ **prompt-injection-firewall** — real-time detection layer between users and an LLM, catching injection / jailbreak / exfiltration attempts, benchmarked against a labeled attack set.
- ☁️ **aws-cost-hygiene-automation** — serverless cleanup of stale AMIs/EBS/snapshots ($300/mo saved in production).
